# AI와 함께 만드는 첫 확장팩

확장팩 제작기는 직접 쓴 이야기, 새 캐릭터와 스킬, 새 전장을 만드는 화면입니다.
원작의 직업·스킬 연출·타일·APD 이름은 **참조값**으로만 저장합니다.
공유 ZIP에는 **mod.json**과 **content.json**만 들어가며 원작 그림·음악·테이블·캐시는 복사하지 않습니다.

## 가장 빠른 시작: AI 연결부터

1. 데이터 연결 화면에서 **확장팩 만들기**를 열고 **새 프로젝트**를 누릅니다.
2. 주인공·연습 상대·스킬·8×8 전장·짧은 이야기가 있는 예제를 새 프로젝트 폴더에 저장합니다.
3. **AI로 만들기 → AI 연결**에서 사용하는 AI를 고르고 **AI 연결 시작 → 연결 설정 복사**를 누릅니다. 복사한 설정을 AI 클라이언트에 등록합니다.
4. AI에게 `ft2_read_project`로 열린 프로젝트를 확인하게 하고 수정할 내용을 요청합니다.
5. 제작기에서 변경된 값·지도·이야기 흐름을 확인하고 원작 기준값과 비교합니다.
6. 필요하면 **↶**로 한 수치를, **원본값으로 전체 초기화**로 캐릭터·스킬의 편집값을 복원합니다.
7. **검사 → 저장하고 테스트 → 저장**으로 실행을 확인합니다.
8. 별도로 열린 게임에서 확인한 뒤 **테스트 중지**를 누릅니다. 제작기와 AI 연결은 유지됩니다.
9. 다른 사람에게 줄 때는 **공유 ZIP 내보내기**를 누릅니다.

[DeepSeek Harness를 포함한 GodotAI 26개 클라이언트 연결 방법](EDITOR_MCP_CLIENTS.md)을 보고 사용하는 AI에 연결하세요.
직접 편집하려면 아래 작업 화면에서 값을 바꾸고 **속성 적용**을 누릅니다.
정품 연결 전에도 프로젝트 작성·저장은 가능하며, 원작 검색·원본값 비교와 실행 테스트는 정품 데이터를 준비한 뒤 사용합니다.

## 작업 화면 읽기

- **왼쪽 목록:** 내가 만든 항목을 선택합니다. 캐릭터·스킬에서는 원작 목록을 검색해 **원작에서 편집본 만들기**로 시작할 수도 있습니다.
- **가운데 작업 화면:** 캐릭터 그림과 능력치 비교, 스킬 수치, 큰 지도 또는 이야기 카드 흐름을 확인합니다.
- **오른쪽 속성:** 선택한 항목의 이름·ID·기반 리소스·연결을 고칩니다. 해당 **적용** 버튼으로 반영합니다.
- **원본 비교·초기화:** 수치마다 현재값과 원작 기준값을 나란히 봅니다. **↶**는 해당 수치만, 전체 초기화는 캐릭터·스킬의 편집값을 되돌립니다. 로컬 ID·기반 참조·레벨은 유지합니다.

캐릭터 수치는 **기본값**과 **레벨당 성장**을 나눠 표시합니다. 시작 레벨에 맞춰 계산된 최종 능력치와 구분하세요.
정품 미연결 상태에서는 원본값을 추측해서 표시하지 않습니다.

## 캐릭터

- 왼쪽 **추가**로 캐릭터를 만듭니다.
- 표시 이름과 시작 레벨을 입력하고 기반 직업·APD 그래픽을 선택합니다.
- 스킬 선택 목록에서 자신이 만든 스킬을 골라 **선택한 스킬을 목록에 추가**합니다.
- **변경**을 켠 능력치만 덮어씁니다. 끈 항목은 기반 직업의 능력치·성장을 사용합니다.
- **속성 적용**을 누릅니다.

스킬은 캐릭터당 최대 10개입니다. ID는 프로젝트 안에서 구분하는 영문 이름이고,
화면에 표시할 이름은 별도로 자유롭게 작성합니다.

## 스킬

**스킬** 탭에서 **추가**를 누르고 새 이름·MP 소비·위력·거리를 정합니다.
기반 스킬은 계산 규칙의 출발점, 연출 스킬은 정품에서 재사용할 모션입니다.
**속성 적용** 뒤 캐릭터 탭에서 해당 스킬을 연결합니다.

v2 첫 버전은 새로운 이름·능력치·거리의 스킬과 기존 연출의 재사용을 지원합니다.
임의의 새 엔진 코드를 폼 안에서 실행하거나 원작 연출 파일을 공유 ZIP에 넣는 기능은 아닙니다.

## 맵과 배치

1. **맵·배치**에서 **추가**를 누르고 맵 이름·크기를 정합니다.
2. 원작 타일을 참조할 기반 맵을 고릅니다. 자체 예제의 기본값은 실제 정품에 있는 맵 40입니다.
3. **맵 속성 적용**을 누릅니다.
4. 가운데 큰 지도에서 칸을 클릭합니다. 좌표는 (1, 1)부터 시작하며 마우스를 올리면 좌표·높이·지형이 표시됩니다.
   휠로 확대·축소하고 가운데 마우스 버튼으로 이동합니다. 중앙 맞춤·그리드 표시도 사용할 수 있습니다.
5. 높이·지형 도구를 고르고 클릭하거나 드래그해서 칠합니다. 오른쪽 속성의 **선택한 칸에 적용**도 사용할 수 있습니다.
6. 캐릭터·진영·레벨을 고른 뒤 **선택한 칸에 배치**합니다.

같은 칸에 두 캐릭터를 놓거나 범위를 벗어난 배치는 검사에서 알려줍니다.
지형 0은 일부 직업이 이동할 수 없으므로, 처음 만들 때는 기본 지형 1을 권합니다.
현재 전투 구조에서는 아군 10명·적군 40명까지 배치합니다.

## 이야기

**스토리**에서 노드를 추가하고 가운데 이야기 카드를 클릭해 종류별 속성을 채웁니다. 연결선은 다음 장면과 전투 승리·패배 경로를 표시합니다.

| 종류 | 입력할 것 |
|---|---|
| 대사 | 화자 캐릭터 ID, 직접 쓴 대사, 다음 노드 |
| 전투 | 전장, 승리 뒤 노드, 패배 뒤 노드 |
| 변수 설정 | 변수 이름, 설정할 값, 다음 노드 |
| 조건 분기 | 변수 이름, 비교할 값, 같을 때·다를 때 노드 |
| 끝 | 이야기 종료 |

각 노드의 **노드 적용**, 스토리의 **스토리 속성 적용**을 누릅니다.
**시작 노드 ID**는 그 이야기의 첫 노드, 화면 위쪽 **처음 시작할 스토리**는
확장팩 전체에서 처음 실행할 이야기입니다.

## 검사와 공유

검사는 ID 중복, 없는 캐릭터·스킬·맵·노드 참조, 잘못된 좌표·범위·능력치를 확인합니다.
형식 검사를 통과한 뒤에도 **저장하고 테스트**로 실제 동작을 확인하세요.

ZIP을 받은 사람은 압축을 푼 후, **mod.json이 들어 있는 폴더**를 커스텀 목록에 연결합니다.
확장팩을 실행하는 사람도 자신의 정품 데이터를 준비해야 합니다.
대사·이름·맵 구성 등에는 직접 작성했거나 배포할 권한이 있는 내용을 사용하세요.

현재 제작기에서 원작 파일 자체를 자동으로 내보내지는 않습니다. 자체 PNG를 새 APD처럼
사용하는 기능이나 새로운 엔진 동작의 제작 UI는 별도 지원 범위입니다.

## 실행과 저장의 현재 한계

- 제작기에서 만든 확장팩은 독립된 확장 에피소드로 시작합니다. 원작 특정 챕터 도중에
  끼워 넣고 다시 그 챕터로 복귀하는 기능은 아직 없습니다.
- 전투 노드마다 배치에 적은 캐릭터·레벨에서 유닛을 새로 구성합니다. 전투 간 HP·장비·
  육성 상태를 원작 파티처럼 자동으로 이어 가는 기능은 제공하지 않습니다.
- 확장 전투의 아군 대기 상태에서 선택/행동을 마친 뒤 일반 저장 메뉴를 사용할 수 있습니다.
  원작 DAT 세이브 대신 확장 스토리·변수·새 맵·유닛 상태를 별도 JSON으로 보존합니다.
- 스토리·맵 등 프로젝트 내용을 바꾸면 저장 프로필이 달라질 수 있습니다. 제작 중 저장본과
  배포 ZIP을 받은 사용자의 저장본을 자동으로 호환된다고 가정하지 마세요.
- 스킬은 기존 스킬의 처리 방식을 기반으로 MP·위력·거리와 표시 이름을 새 정의로 만듭니다.
  기반 처리와 연출을 고르는 것만으로 임의의 새로운 엔진 동작이 생기지는 않습니다.
- 높이·지형은 새 격자의 게임 판정 값입니다. 기반 맵에 특정 지형의 그림이 없으면 다른
  기본 타일로 표시될 수 있으며, 현재 화면은 세밀한 타일 그림 페인터가 아닙니다.

직접 JSON을 작성하는 사람은 [v2 실행 계약](EXTENSION_RUNTIME_CONTRACT.md)과
[v1 호환 규격](FORMATS.md)을 확인하세요. 이 문서와 자체 예제의 재사용 범위는
[EXAMPLES_LICENSE](../EXAMPLES_LICENSE)에 명시되어 있습니다.
