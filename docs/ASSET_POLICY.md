# 공개 모드에 넣을 자료의 경계

공유할 파랜드 2 확장팩(모드)은 **변경 지시와 직접 만든 자료**로 구성하고, 원작 자료는 각 사용자가
자기 정품 설치에서 읽도록 설계합니다. 이 문서는 프로젝트의 파일 분리 지침이며
저작권 침해가 없다는 법적 보증은 아닙니다.

배포 전에 다음을 확인하세요.

- 원작 EXE·DLL·전체 DAT·맵·대사·이벤트 덤프·추출 이미지·음악·효과음이 들어 있지 않은가?
- 개인 캐시 전체, `raw_record_hex`, 캡처한 글꼴 마스크나 운영체제 글꼴 파일을 복사하지 않았는가?
- 원작 자료의 확장자만 바꾸거나 JSON/PNG로 변환한 것을 새 저작물로 간주하고 있지 않은가?
- 새 그림·소리·글꼴·SoundFont를 넣는다면 직접 만들었거나 해당 배포 조건을 확인했는가?
- 가격/MP 같은 변경은 필요한 ID와 값의 `table_edits`로 표현할 수 있는가?
- 실제 게임 자료가 필요한 검증은 각자의 정품으로 재현하고, 공개 테스트는 자체 합성 자료로 만들었는가?
- 모드 설명에 지원 엔진 버전, 필요한 정품 판본, 적용 순서와 알려진 제한을 적었는가?

원작을 보유해야 실행되는 모드라는 사실만으로 모든 재배포가 허용되지는 않습니다.
출처가 있는 자료를 사용할 때는 그 자료에 적용되는 권리와 조건을 별도로 확인하세요.
정품 보유가 원작의 수정·공개·재배포 전권을 주는 것은 아니며, 로컬 참조나 변환 레시피만
공유하는 방식도 제공자의 책임을 자동으로 없애 주는 법적 보증이 아닙니다.
