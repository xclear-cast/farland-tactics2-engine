# 처음 사용하는 분을 위한 사용 설명서

## 1. 무엇을 받아야 하나요?

[다운로드 페이지](https://github.com/xclear-cast/farland-tactics2-engine/releases)에서 다음 파일을 받습니다.

- Windows 11: **FT2-Windows-x64.zip**
- Mac M1 이상: **FT2-External-macos-arm64.zip**

`Code → Download ZIP`은 개발용 소스입니다. 게임을 실행하려면 위 실행 패키지를 받으세요.
Python은 따로 설치하지 않아도 됩니다.

## 2. 어느 폴더에 넣나요?

다운로드한 ZIP을 새 폴더에 **전부 압축 해제**합니다. 실행 파일과 함께 들어 있는 폴더를 그대로 보관합니다.
정품 게임 폴더와 엔진 폴더는 다음처럼 따로 둡니다.

```text
내 게임/
├─ 파랜드2 정품/
│  ├─ DATA/
│  ├─ MAP/
│  ├─ SPRITE/
│  └─ FTO_O.EXE
└─ FT2 커스텀 엔진/
   └─ 다운로드한 ZIP의 파일과 폴더 전체
```

## 3. 무엇을 실행하나요?

- Windows: 압축을 푼 폴더의 **Launch-Windows.cmd**를 두 번 클릭합니다.
- Mac: 압축을 푼 폴더의 **FT2 External Engine.app**을 두 번 클릭합니다.

Mac 실행이 차단되면 [README의 Mac 실행 안내](../README.md#3-운영체제에-맞는-시작-파일을-더블클릭하세요)를 확인하세요.

## 4. 정품 게임을 연결하세요

제작기를 먼저 열었다면 상단 **원작 데이터 연결**을 누르세요. 연결 후 같은 편집 프로젝트로 돌아오며, **원작 폴더 열기**로 연결한 폴더를 확인할 수 있습니다.

1. 앱에서 **폴더 선택**을 누릅니다.
2. `DATA`, `MAP`, `SPRITE`, `FTO_O.EXE`가 함께 들어 있는 **파랜드2 정품 폴더**를 고릅니다.
3. **게임 준비하기**를 누르고 완료될 때까지 기다립니다. 처음에는 몇 분 걸릴 수 있습니다.
4. 준비가 끝나면 **연결하고 실행**을 누릅니다.
5. 실행 옵션을 확인하고, 타이틀에서 **처음부터**를 누릅니다. 원작 도입 로고와 프롤로그부터 시작합니다.

본편의 새 게임과 에디터의 **저장하고 테스트**는 다릅니다. 후자는 편집 중인 확장팩을 실행합니다.
원작 폴더에 저장 파일이 있다면, 처음 플레이할 때는 저장 불러오기 대신 **처음부터**를 선택하세요.

다음 실행부터는 저장된 연결 설정을 사용합니다. 빈 세이브 슬롯은 정상적으로 건너뜁니다.
0.2.0 버전에서 빈 슬롯 오류가 났다면 **0.2.1 이상**을 받아 게임 준비하기를 다시 누르세요.

## 5. AI에 연결해서 나만의 확장팩을 만드세요

1. 게임을 닫고 엔진 폴더의 **Game-Setup-Windows.cmd** 또는 **Game-Setup-Mac.command**를 실행합니다.
2. **확장팩 만들기 → 새 프로젝트**로 기본 예제를 열고, 새 확장팩 폴더에 저장합니다.
3. **AI로 만들기 → AI 연결**에서 사용하는 AI를 고르고 **AI 연결 시작 → 연결 설정 복사**를 누릅니다. 복사한 설정을 해당 AI 클라이언트에 등록합니다.
4. AI에게 “열린 FT2 프로젝트를 확인하고 주인공의 HP만 원작보다 10 올려줘”처럼 요청합니다.
5. 제작기 왼쪽 목록에서 항목을 선택하고, 가운데 작업 화면과 오른쪽 속성에서 바뀐 값을 확인합니다.
6. 원치 않는 변경은 수치 옆 **↶** 또는 **원본값으로 전체 초기화**로 되돌립니다.
7. **검사 → 저장하고 테스트 → 저장** 순서로 결과를 확인합니다.
8. 테스트는 별도 게임으로 열립니다. 확인 후 **테스트 중지**를 누릅니다. 제작기와 AI 연결은 계속 사용할 수 있습니다.
9. 완성한 확장팩은 **공유 ZIP 내보내기**로 나눕니다.

AI를 쓰지 않을 때도 같은 화면에서 직접 값을 고치고 **속성 적용**을 누르면 됩니다.
맵 화면은 휠로 확대·축소하고 가운데 마우스 버튼으로 이동합니다. 지도 칸과 이야기 카드를 클릭하면 해당 항목을 편집합니다.

[DeepSeek Harness 등 AI 26개 연결 설정](EDITOR_MCP_CLIENTS.md)과 [자세한 제작기 사용법](EXPANSION_EDITOR.md)을 참고하세요.

## 6. 다른 사람이 만든 확장팩을 실행하세요

1. 받은 확장팩 ZIP을 별도 폴더에 풉니다.
2. **Game-Setup** 실행 파일을 열고 **추가 옵션**을 펼칩니다.
3. **커스텀 모드 폴더**에 `mod.json`이 들어 있는 폴더 경로를 넣습니다.
4. **연결하고 실행**을 누릅니다.

여러 확장팩은 한 줄에 하나씩 입력하며 아래쪽 항목이 우선합니다.
실행하는 사람도 자신의 정품 데이터를 준비해야 합니다.

## 7. 배경음악(BGM)과 효과음 안내

- **효과음(SFX)은 기본 제공됩니다**: 정품 게임 폴더(`DATA/`)에 효과음 데이터가 포함되어 있으므로 별도 준비 없이 바로 재생됩니다.
- **배경음악이 나오지 않을 때**: 사운드폰트(`.sf2`)나 CD 오디오 음원 없이 변환하면 캐시(`content.json`)의 `capabilities.audio`가 `{"cdda_tracks": 0, "soundfont": false}`로 기록되며, 실행 시 `"배경음 자료가 없어 BGM을 사용하지 않습니다. 효과음은 사용할 수 있습니다."` 안내가 표시됩니다(`game/scripts/audio/ft2_audio.gd`). 이는 엔진 오류가 아니라 선택적 배경음 자료가 아직 연결되지 않은 상태입니다.
- **MIDI 배경음(사운드폰트 `.sf2`) 연결 절차**:
  1. General MIDI 호환 `.sf2` 파일(예: `TimGM6mb.sf2`)을 준비합니다(저작권·저장소 경계 정책상 저장소에는 포함하지 않습니다).
  2. 변환 시 `--soundfont` 옵션을 지정해 실행합니다:
     ```sh
     python tools/convert_installation.py --source "<정품 게임 폴더>" --output "<개인 캐시 폴더>" --soundfont "<경로/TimGM6mb.sf2>"
     ```
  3. 변환이 완료되면 캐시 내 `assets/audio/TimGM6mb.sf2`와 `content.json`의 해시 목록이 갱신되고 `capabilities.audio.soundfont`가 `true`가 됩니다.
  4. `soundfont: true` 상태에서는 런타임(`game/scripts/midi_output/ft2_midi_output.gd`)이 GDExtension 네이티브 신스(`FT2NativeSynth`, `game/native/bin/ft2synth.dll` · `libft2synth.so` · `libft2synth.macos.arm64.dylib`)를 통해 사운드폰트와 MIDI 데이터를 로드하여 실시간 오디오 스트림으로 재생합니다.
- **CD 오디오(CDDA) 배경음 연결 절차**:
  - 원작 CD 오디오 트랙(트랙 2~23) 파일이 들어 있는 폴더가 있다면 `--cdda-dir "<CD 음원 폴더>"` 옵션을 함께 지정해 변환합니다(`--soundfont`와 동시에 지정 가능).
- **재변환과 캐시 재사용 규칙 (`tools/convert_installation.py`)**:
  - 변환기는 변환 스크립트·`tools/converters/font_charset.json`의 해시(`pipeline_sha256`), 정품 폴더 파일 해시(`source_files`), 그리고 오디오 입력 해시(`audio_inputs`: 지정한 `.sf2` 및 CD 트랙 파일 해시)가 모두 일치할 때만 기존 캐시를 재사용합니다.
  - `--soundfont` 또는 `--cdda-dir`을 새로 추가하거나 바꾸면 `audio_inputs`가 변경되어 자동으로 재변환되며, 필요 시 `--force`로 전체 재변환을 강제할 수 있습니다.
