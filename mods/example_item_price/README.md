# 기존 아이템 가격 변경 예제

`mod.json`만 있는 가장 작은 수치 모드입니다. 기존 1번 아이템의 가격을 10으로
설정하며 원작 이름·아이콘·DAT 레코드를 포함하지 않습니다.

연결 화면의 모드 목록에 이 폴더의 경로를 넣고 실행하세요. 수정할 때는 별도로
복사한 뒤 `id`를 자신만의 값으로 바꿉니다. 원하는 ID는 자신의 개인 캐시에서 확인하고,
전체 캐시나 원작 테이블을 모드에 복사하지 마세요.

다른 모드가 같은 항목을 바꾸면 목록에서 더 아래에 있는 모드가 우선합니다.
[모드 제작 안내](../../docs/MODDING.md)를 참고하세요.
